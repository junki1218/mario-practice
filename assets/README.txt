画像アセットについて
====================

現在このフォルダには以下の2枚が配置済みです。

- mario.png … ゲーム画面でマリオを表示するキャラクター画像
              （前の人の単語が長くなるほど大きく表示される。
              js/data.js の VISUAL_CONFIG で拡大縮小の範囲を調整可能）
- bg.png    … ゲーム全体の背景画像（薄く／低い不透明度で表示）

背景画像の差し替え方法
----------------------
1. このフォルダ (assets/) に新しい画像ファイルを置く
2. css/style.css の :root ブロックにある

     --bg-image: url('../assets/bg.png');

   のファイル名部分を差し替える

背景の薄さ（不透明度）を変えたいとき
------------------------------------
同じ :root ブロックの

     --bg-opacity: 0.16;

   の数値を 0（透明）〜 1（不透明）の間で調整してください。

マリオ画像を差し替えたいとき
----------------------------
assets/mario.png を別の画像に差し替えるだけでOKです。
（透過PNG推奨。サイズはjs/data.jsのVISUAL_CONFIGで自動調整されます）

コインフェーズの表示
--------------------
コインフェーズ中はマリオ画像の代わりにコイン絵文字（🪙）を表示します。
仕様書4章のとおり「何枚目のコインか」は表示しないため、絵文字サイズは
常に一定（js/data.js の VISUAL_CONFIG.coinSizePx）です。
